# Публикация демо-стенда для проверяющего

Два способа. Первый работает без включённого компьютера, второй проще и быстрее.

## Вариант 1. Render (бесплатно, без банковской карты)

Ограничения бесплатного тарифа (на ноябрь 2026): сервис засыпает после 15 минут без запросов, первое открытие после сна занимает до минуты; бесплатная БД PostgreSQL удаляется через 30 дней после создания; Redis в бесплатном варианте не используется (кэш и сессии в памяти процесса).

1. Репозиторий должен быть на GitHub (файл `render.yaml` в корне).
2. Зарегистрироваться на https://render.com (через GitHub).
3. **New -> Blueprint**, выбрать репозиторий `room-booking`, ветку `main`.
4. Render покажет сервис `room-booking` и базу `booking-db`. В поле `DJANGO_SUPERUSER_PASSWORD` ввести пароль администратора (запомнить его).
5. **Apply / Deploy**. Первая сборка занимает 5-10 минут.
6. Адрес сайта: `https://room-booking-xxxx.onrender.com` (в карточке сервиса). Проверить `/health/` и `/api/docs/`.

При запуске автоматически выполняются миграции, создаются демо-данные (`seed_demo`) и администратор `admin`.

## Вариант 2. Временная ссылка на локальный стенд (Cloudflare Tunnel)

Подходит на время проверки, пока компьютер включён и проект запущен.

1. В `.env` добавить (после проверки вернуть как было):
   ```
   DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1,.trycloudflare.com
   DJANGO_CSRF_TRUSTED_ORIGINS=https://*.trycloudflare.com
   DJANGO_BEHIND_PROXY=1
   ```
2. `docker compose up -d` (из папки проекта).
3. Создать туннель:
   ```
   docker run --rm cloudflare/cloudflared:latest tunnel --no-autoupdate --url http://host.docker.internal:8000
   ```
4. В выводе найти адрес вида `https://слова-слова.trycloudflare.com` и передать проверяющему. Закрытие окна с командой закрывает доступ.

## Учётные записи для проверяющего

| Логин | Пароль | Роль |
|---|---|---|
| `ivan`, `maria`, `petr` | `demo12345` | пользователь |
| `manager` | `demo12345` | администратор (без доступа к Django-админке) |
| `admin` (только Render) | заданный при деплое | суперпользователь, Django-админка `/admin/` |

Что посмотреть: `/rooms/` (комнаты и занятость), бронирование в обычной и VIP-комнате («Конференц-зал»), `/manage/pending/` (подтверждение заявок), `/manage/report/` (отчёты и CSV), `/api/docs/` (Swagger), `/health/`.

## После проверки

Удалить сервис и базу в панели Render (Settings -> Delete), не хранить на демо-стенде реальные данные.
